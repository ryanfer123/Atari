# Native Android layer

This directory is reserved for the Android host generated by Flutter and ATARI's
Kotlin platform integrations.

Planned responsibilities include:

- `UsageStatsManager` application-transition collection
- device unlock and screen-state tracking
- `NotificationListenerService` timing metadata
- permission and special-access flows
- background workers and OEM-specific lifecycle handling
- Flutter platform-channel integration

Behavioral content such as messages, notification text, screenshots, camera
input, and microphone recordings is outside the core collection boundary.
